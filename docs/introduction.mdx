# 📘 Introduction

## Overview
Oraxen allows you to customize your Minecraft server by allowing the creation of new blocks, items, and recipes. 
This can be accomplished entirely through a resource pack and server-side implementation, eliminating the requirement for any client-side mod installations.

## How It Works
Oraxen reads your configuration files and uses them to generate a Minecraft resource pack that will then be uploaded to a resource pack server which then sends the pack to players joining your server.

## Version
Oraxen is developed and designed for the <Highlight color="#1877F2" to="https://papermc.io/downloads/paper">**Paper**</Highlight> Server Software. It is compatible with most common Paper forks such as Purpur and <Highlight color="#1877F2" to="https://papermc.io/software/folia/">**Folia**</Highlight>. Oraxen is a Paper plugin and cannot load on Spigot or CraftBukkit.

Oraxen includes support for versions from **1.20.1** up to **26.3**.<br />

Oraxen has ViaVersion support, for that please read the documentation <Highlight color="#2E8B57" to="./compatibility/viaversion">**here**</Highlight>.

## Installation
Drag and drop the `.jar` file into your server's `/plugins` folder and restart your server.<br />
On servers <Tooltip trigger={<code>&lt;1.21.2</code>}>Below `1.21.2`.</Tooltip>, also install <Highlight color="#1877F2" to="https://modrinth.com/plugin/packetevents/versions?l=paper">**PacketEvents**</Highlight>.
