# 🪑 Furniture

## Overview
Oraxen lets you create custom furniture using the `furniture` mechanic.<br />

<img src="/assets/furniture/sitting.gif" alt="Sitting on a furniture." width="650"/>

## Configuration
Furniture is configured as items in `.yml` files inside the `plugins/Oraxen/items` folder.

## Barriers and hitboxes

<code>barriers</code> places solid collision blocks relative to the furniture. Each entry uses integer coordinates in the form <code>x,y,z</code>. <code>hitboxes</code> adds interaction areas without placing solid collision blocks.

```yaml
mechanics:
  furniture:
    barriers:
      - 0,0,0
      - 0,0,1
    hitboxes:
      - 0,0,0 1,2
```

## Appearance

The top-level <code>pack</code> section controls the item shown in inventories. Use <code>mechanics.furniture.appearance</code> to set the model and textures used by placed furniture.

```yaml
chair:
  material: PAPER
  pack:
    model: furniture/chair_inventory
  mechanics:
    furniture:
      type: DISPLAY_ENTITY
      barriers:
        - 0,0,0
      appearance:
        model: furniture/chair_placed
        generate_model: false
        models:
          grown: furniture/chair_grown
```

The <code>appearance</code> section accepts the model, texture, and model-generation options documented on the [Appearance page](/configuration/items/appearance). Use <code>appearance.models</code> to assign models to named growth stages. The placed model can differ from the inventory item model.
