# 🏳️ Languages

## Overview
Minecraft uses language components for text throughout the game, including menu labels, inventory titles, item descriptions and messages.
Oraxen lets you override these components through the resource pack.

## Configuration
Configure language overrides in `plugins/Oraxen/pack/lang`.

<PluginFileTree
  initialTreeData={[
    {
      id: "plugins",
      name: "plugins",
      children: [
        {
          id: "plugins/Oraxen",
          name: "Oraxen",
          children: [
            {
              id: "plugins/Oraxen/pack",
              name: "pack",
              children: [
                {
                  id: "plugins/Oraxen/pack/lang",
                  name: "lang",
                  children: [
                    { id: "plugins/Oraxen/pack/lang/global.json", name: "global.json", isLeaf: true },
                    { id: "plugins/Oraxen/pack/lang/en_us.json", name: "en_us.json", isLeaf: true },
                    { id: "plugins/Oraxen/pack/lang/de_de.json", name: "de_de.json", isLeaf: true }
                  ]
                }
              ]
            }
          ]
        }
      ]
    }
  ]}
/>

```yml
{
  "container.inventory": "", # Replaces the "container.inventory" component with nothing.
  "menu.returnToGame": "Return to the server" # Replaces the "menu.returnToGame" component with "Return to the server".
}
```


### Overrides
Use `global.json` to override a component for all Minecraft languages.<br />

```json title="plugins/Oraxen/pack/lang/global.json"
{
  "container.inventory": "",
  "menu.returnToGame": "Return to the server"
}
```

For example, `container.inventory` controls the **Inventory** text in the player inventory.

Use a locale file such as `en_us.json`, `de_de.json` or `fr_fr.json` to override a component only for players using that language.<br />

```json title="plugins/Oraxen/pack/lang/de_de.json"
{
  "menu.returnToGame": "Zurück zum Server"
}
```

Oraxen adds the entries from `global.json` to every locale during pack generation. If a locale file defines the same component, the language-specific value takes priority.

See the <Highlight color="#1877F2" to="https://assets.mcasset.cloud/26.3/assets/minecraft/lang/en_us.json"><strong>full list of language components</strong></Highlight>.<br />

<Callout type="important">
    Minecraft supports named <Tooltip trigger="color codes">`<red>`, `<gray>`, `<blue>`</Tooltip> in language overrides, but not <Tooltip trigger="hex colors">`<#FF55AA>`</Tooltip>.
</Callout>
