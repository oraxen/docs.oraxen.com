# 🕹️ Usage

## Overview
FeatherConvert is an extension that makes it possible to use Oraxen resourcepacks on Bedrock.

<Callout type="important">
	FeatherConvert is an Oraxen partner, therefore Links on this page may be affiliate links.
</Callout>

## Purchasing

## Support

- For more advanced support, you can join the <Highlight color="#ba862b" to="https://discord.gg/noviac">**Noviac Discord**</Highlight> (creators of the Extension).

## Version
FeatherConvert is developed and designed for the <Highlight color="#1877F2" to="https://papermc.io/downloads/paper">**Paper**</Highlight> Server Software. It is compatible with most common forks of Paper.
It includes support for versions starting from **1.21+**.

## Installation
Drag and drop the `.jar` file into your server's `/plugins` folder and restart your server.
