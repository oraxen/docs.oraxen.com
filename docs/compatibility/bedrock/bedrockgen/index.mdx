# 🪶 BedrockGen

## Overview
BedrockGen converts the Java resource pack generated by Oraxen into the Bedrock resource pack and mappings required by Geyser. This lets Bedrock players use supported Oraxen content without moving it to another content plugin. It can also adapt resource-pack-driven interfaces, including chest GUIs, Oraxen HUDs, and LuxDialogues, for Bedrock players.

## Version
BedrockGen is developed and designed for the <Highlight color="#1877F2" to="https://papermc.io/downloads/paper">**Paper**</Highlight> Server Software. It is compatible with most common forks of Paper.
It includes support for versions starting from **1.21+**.

## Installation
Drag and drop the `.jar` file into your server's `/plugins` folder and restart your server.
