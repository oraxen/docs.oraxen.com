# 🪶 BedrockGen

## Overview
BedrockGen converts the Java resource pack generated by Oraxen into the Bedrock pack and Geyser mappings that Bedrock players need. Bedrock players see the same items, blocks, armor and furniture as Java players without moving content to another plugin. The companion add-on BGHud can also draw resource-pack-driven interfaces on Bedrock, including Oraxen HUDs and LuxDialogues.

## Requirements
* A <Highlight color="#1877F2" to="https://papermc.io/downloads/paper">**Paper**</Highlight> server on **1.21.4 or newer**, or a common Paper fork. Folia works too.
* **Geyser 2.11 or newer**, on the proxy or as Geyser-Spigot. Add Floodgate as well if your other plugins need to recognise Bedrock players.

## Installation
BedrockGen ships as three files.

| File | Goes into | Its job |
| --- | --- | --- |
| `BedrockGen.jar` | `plugins/` on the Paper server | Converts the Oraxen pack and writes the Bedrock output |
| `BedrockGen-Int.jar` | `plugins/` on the same Paper server | Sends the output to Geyser and handles server-side features such as custom elytras |
| `BedrockGen-Ex.jar` | the `extensions/` folder where Geyser runs | Serves the pack and draws furniture and models for Bedrock players |

On a network, put BedrockGen and Int on every backend you convert and Ex once where Geyser runs. Restart so Geyser picks up the extension, then link the two sides as described on the <Highlight color="#1877F2" to="./usage">**Usage page**</Highlight>.
