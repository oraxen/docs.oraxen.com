# 🔧 ModelEngine

## Overview
Oraxen imports ModelEngine's resource pack automatically when it generates its own pack. Automatic import is enabled by default. Oraxen waits for ModelEngine to finish generating its pack and then uses the latest available pack.

<Callout>
  Do not use ModelEngine item types, such as Leather Horse Armor, as materials in Oraxen items or other merged packs.
</Callout>

<Callout type="important">
    ModelEngine may include core shader files that conflict with Oraxen. Exclude them from imported packs with this setting.

    ```yaml
    pack:
      import:
        exclude:
          core-shaders: true
    ```
</Callout>

## Manual import
Automatic import is controlled by `pack.import.modelengine`. If you disable it, you can add the ModelEngine pack through the [pack merging guide](/usage/merging).
Choose one of the manual methods below when you need to manage the pack yourself.

<Callout type="note">
  We recommend the ZIP file uploads, since they are the easiest to maintain if you want to update the ModelEngine pack.
</Callout>

<details>
<summary id="zip-file-uploads"><strong>ZIP file uploads</strong></summary>
1. Go to your ModelEngine folder (`plugins/ModelEngine`)
2. Open the resource pack folder (`plugins/ModelEngine/resource pack`)
3. Select the assets folder (`plugins/ModelEngine/resource pack/assets`)
4. Compress the selected (assets) folder (Compress to ZIP file)
5. Copy / Move the compressed ZIP file into Oraxen's upload folder (`plugins/Oraxen/pack/uploads`)
<Callout type="important">
  Make sure to select the assets folder, not its contents. If other packs are overwriting modelengine, rename the ZIP file to 99_modelengine for it to take priority.
</Callout>
</details>

<details>
<summary id="direct-folder-structure"><strong>Direct folder structure</strong></summary>
1. Go to your ModelEngine folder (`plugins/ModelEngine`)
2. Open the resource pack folder (`plugins/ModelEngine/resource pack`)
3. Copy the assets folder (`plugins/ModelEngine/resource pack/assets`)
<Callout type="important">
  Make sure to copy the assets folder, not its contents.
</Callout>
4. Paste the assets folder into Oraxen's pack folder (`plugins/Oraxen/pack`)
</details>
