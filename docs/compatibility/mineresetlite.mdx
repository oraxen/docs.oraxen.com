# ⛏️ MineResetLite

## Overview

MineResetLite is compatible with Oraxen. It allows you to use Oraxen custom blocks inside regenerating mines.

## Usage

Use the Oraxen block ID in your MineResetLite mine configuration.

```yaml
blocks:
  - oraxen:custom_block_id
```

Replace `custom_block_id` with the ID of your Oraxen block.
