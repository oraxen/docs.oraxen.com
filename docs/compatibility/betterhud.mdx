# 🖨️ BetterHUD

## Overview
Oraxen allows you to configure BetterHUD and Oraxen to be fully compatible together. For BetterHUD to display the custom textures, you have to merge BetterHUD's Pack into Oraxen's Pack.

## Merging
Merging a pack into Oraxen is simple and we have a dedicated documentation page for it <Highlight to="https://docs.oraxen.com/usage/merging" color="#2E8B57">**here**</Highlight>.

1. Go to Oraxen's settings.yml (`plugins/Oraxen/settings.yml`)
2. Ensure `utils.hide.scoreboard.numbers` is set to `false`. (`plugins/Oraxen/settings.yml`)
3. Ensure `pack.import.exclude.core-shaders` is set to `false`. (`plugins/Oraxen/settings.yml`) Otherwise BetterHUD's core shaders will not be merged into the pack.
4. Ensure you have no animated glyphs configured. (No glyphs of the <Highlight color="#1877F2">**Animation**</Highlight> type) <Highlight color="#e74c3c">**Optional**</Highlight>
5. Edit your BetterHUD configuration to have the `build-folder-location` set to `Oraxen/pack/uploads/BetterHUD` and `pack-type` to `zip` in the `BetterHUD/config.yml`.

<Callout type="info">
	Oraxen will merge BetterHUD's `pack.mcmeta` into Oraxen's `pack.mcmeta`.
</Callout>

<Callout type="warning">
	If you run into any issues, `core shaders` are a likely cause. Both BetterHUD and Oraxen use core shaders, which can cause conflicts because core shaders cannot be merged.
	Set `pack.import.exclude.core-shaders` to `false` to keep imported core shaders in the pack. Setting it to `true` removes them and may prevent BetterHUD features from working.
	You can also disable Oraxen's core shader generation.
	Keep `utils.hide.scoreboard.numbers` set to `false` and disable animated glyphs if their shader conflicts with BetterHUD.
</Callout>
