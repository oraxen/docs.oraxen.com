# Documentation guidance

Assume readers use the latest Oraxen version. Do not add Oraxen release-version requirements or say that older Oraxen versions lack a feature. State Minecraft, server, or external dependency version requirements when they affect current behavior.

Do not discuss older configuration formats, whether old configurations are migrated, or whether old settings are deprecated or already migrated. Document the current configuration format and behavior.

Before adding documentation, inspect the surrounding page and integrate changes into its existing structure and style. Use the same format as comparable entries, such as a `<details>` section for a recipe type, and keep the content concise.
